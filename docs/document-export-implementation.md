# 单据与附件关联清单导出

状态：已完成本地实现，全部七十九项检查（七十七项浏览器场景、两项 CSV 编码场景）、格式、静态检查、类型检查及构建通过；推送及生产发布待单独授权。不增加数据库接口、迁移、依赖或云服务，不读取真实资料，不下载或更改生产原件。统一进度见[实现状态](implementation-status.md)。

## 入口与范围

单据记录和流转办理共用 `DocumentsView.vue`；在原筛选表单下增加“导出单据 CSV”和“导出附件关联 CSV”。按点击时的搜索、类型及状态重新查询，不需要先点击查询。文件包含全部匹配且当前账号可见的记录，不依赖页面旧结果。

管理员、经办人、查询人沿用原读取权限。管理员可见全部草稿，经办人只见自己的草稿，查询人不能读取草稿；范围由现有 `list_documents` 和 `list_evidence` 核对。附件功能未开放时，不显示关联导出入口，单据清单仍可使用。

## 文件内容

| 清单 | 内容 |
| --- | --- |
| 单据 | 单据标识、正式单号、类型、草稿/确认/作废状态、实际交接日期、双方、实际移交接收人、双方负责人、设备数、签字件状态、创建和确认时间、作废原因及备注 |
| 附件关联 | 单据标识、单号、类型、状态、实际交接日期、双方及签字件状态；附件标识、原文件名、上传及核对状态、是否有效、内部或外部来源、外部凭证编号、字节数、页数、SHA-256、上传时间及更正原因 |

正式单据优先使用已有双方冻结快照；草稿没有正式单号，保持空白并注明草稿及签字件状态不适用。不虚构编号或归档事实；已作废单仍显示作废状态，其原件关联继续可追溯。文件保留接口允许当前账号读取的停用附件、待上传及失败记录，分别标注，不能把它们当作有效签字件。

关联清单一行对应一个可见附件，不为没有附件的单据生成假附件行；无附件时生成列标题。单据清单中的待回传状态用于核对缺件。文件不包含 `storage_key`、桶、API/CDN 地址、临时下载链接或授权凭据；本轮没有原件批量下载功能。

时间点继续由数据库以 UTC 保存，CSV 显示为东八区并在列名标明；交接日期保持纯日期。文件名使用东八区当前日期。编码、引号和多行转义、公式防护及 Excel 文本列导入规则沿用[公共 CSV 约定](list-export-implementation.md#公共实现与文件规则)。

## 复用与一致性

两处新入口继续共用 [ListExport.vue](../web/src/components/ListExport.vue)、[csv.ts](../web/src/csv.ts) 与中文错误映射；字段与关联读取集中在 [document-export.ts](../web/src/document-export.ts)。签字件状态中文映射放在 `evidence-model.ts`，由原附件面板和导出共用，不维护两份状态名称。

单据清单只需一次现有列表查询。附件清单先读取匹配单据，再逐单读取元数据，适用于当前很小的单据量；任何一单请求失败，整次导出失败，不下载部分成功文件。单据版本或签字件状态与初始列表不一致，或附件所属单据不匹配时，也停止并提示重新核对后重试。

多次读取不构成整个数据库的同一事务快照；版本核对只拒绝读取时已发现的变化，不承诺下载后业务仍不变。页面不写入已确认事实，不更改核对或归档状态。

公共导出组件增加取消信号和可配置按钮文案。成员、角色、权限变化或退出页面后使结果失效，关联读取停止发起后续请求，旧结果不能下载。单据记录与流转办理复用同一页面组件，切换这两个入口也会重建导出上下文；已经发出的单次 RPC 仍受原十五秒超时约束，不宣称可以撤销服务端已开始的读取。

## 检查与发布边界

新增八个浏览器场景，使用已有虚构 Auth/RPC，检查真实 CSV 下载内容：三种角色与草稿范围、未点击查询的新筛选、冻结快照、UTC 跨东八区日期、已作废单、附件关联、停用或上传中状态、不包含存储路径、单次拒绝后的整次失败、版本及关联冲突、重新导出、空结果，以及失权或切换复用页面后的中止。同时将原有故障及维修回归的成功提示断言限定到对应文本，避免异步刷新时两个状态元素造成定位歧义，不改变业务行为。检查不发邮件，不上传原件，不连接生产业务。

本轮准备完成后须单独授权推送，才通过既有 CI/CD 发布；无需数据库迁移或后端配置。原有台账和临时清单导出已上线。实际登录后下载、Excel 导入和大陆访问仍待本人验收；原件批量导出及网站、数据库和附件整体备份恢复继续留在后续阶段。
