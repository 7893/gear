## 人员与团队

`/#/parties` 提供个人和团队名单、文字搜索、类别与启用状态筛选，复用已有分页组件，默认每页二十条，可选十、二十、五十或一百条。停用对象可切换筛选查看。详情显示资料、当前在用设备关联数量、作为有效团队默认负责人的数量及修改历史。

管理员和经办人可修改名称、人员类型、所属单位、联系方式、默认负责人及备注，并办理停用、恢复。修改必须填写原因，保留前后资料和操作者；个人与团队类型不可互换。不改登录账号、已有设备分配或正式单据快照。

停用只阻止新的领用选择，不代表设备归还，也不结束现有临时使用提醒。原持有方和负责人即使停用，仍可按真实情况办理退回或转出。修改团队默认负责人只影响以后填表，现有设备负责人需另办负责人交接。人员仍被有效团队设为默认负责人时，先更换团队默认负责人才能停用；停用团队可保留原负责人，恢复前需选择有效个人。

新增与修改共用 `PartyFields`；原建账及流转中的快速创建继续复用 `PartyQuickCreate`。已有创建请求未提供联系方式时，保留旧请求内容的去重兼容，不因迁移把一次重试误作另一条创建。

## 遗失、报废、找回与误建作废

设备详情新增管理员专用入口，处理前填写日期、原因并明确勾选确认。查询人与经办人没有处置权限，后端同样检查当前已验证的有效管理员身份。

| 操作 | 允许状态与结果 |
| --- | --- |
| 遗失 | 在管设备退出管理，关闭当前分配与到期提醒；历史保留最后责任方，不登记成正常退回 |
| 报废 | 在管设备退出管理并保留处置说明；不允许直接通过“找回”恢复报废设备 |
| 找回 | 仅遗失设备，确认同一实物，沿用内部编号；明确当前状况、位置、库存或个人/团队持有关系，重新选择长期/临时及期限 |
| 误建作废 | 仅初始建账且没有后续状态事件或任何关联单据；当天记录无效原因并关闭初始分配，不删除记录或复用编号 |

找回不重新生成设备，也不自动打开旧分配或复制旧期限。实际仍由人员或团队持有时，创建一条新的分配，起始日期为实际找回确认日期，经办人为本次管理员；故障设备可如实登记为持有中故障。临时期限可按已发生事实记录为逾期，但不能早于本次找回日期。

设备历史读取包含事件前后快照，退出记录显示原持有方、最后负责人和原期限。原始单据、附件、编号、建账时间及原分配历史保留；遗失、报废和找回不虚构交接单。

处置日期不能晚于东八区业务当天，也不能早于已有有效状态事实。新事件触发器补充阻止后续交接、故障或维修回填到已记录的退出/找回日期之前；不把退出日期写成实际交接日期。后续处置为有效状态依赖，原单据不能绕过依赖直接作废。

报废事实的管理员专门纠错、事件证明材料附件和团队内另记具体使用人不属于本轮；本轮不提供任意恢复状态或改写历史的入口。
