## 按接收对象核对设备

在人员或团队详情直接查看“持有与关联设备”，按对象内部 ID 查询，不能用同名人员或相似团队名称替代身份。默认列本人或团队直接持有的设备；个人另可选择负责的团队设备、团队内具体使用或全部关联。全部关联中同一设备只列一次，关联类型可同时标明负责人和具体使用人。

只列在管、有效台账中的当前分配。已退回、已退上游、遗失、报废和无效记录不计入当前持有清单；历史仍可从原设备与原单查询。人员或团队停用不等于归还，其当前未结束分配仍需列出。

复用设备台账的 `AssetTable` 和现有分页，默认每页二十条，可选十、二十、五十或一百条。持有清单 CSV 在导出时重新读取，包含全部匹配记录，不限当前页；记录核对对象标识、对象名称、关联类型及设备字段，防止同名对象混账。CSV 继续使用中文表头、UTF-8 BOM、统一引用及公式中和规则；不含附件原件。

## 团队具体使用人

设备详情中管理员和经办人可以为当前团队持有设备补录、更换或清空具体使用人，必须填写原因。具体使用人来自有效个人名册，支持本单位、借调、挂职及临时等既有人员类型，不要求注册登录账号；查询人只读。

个人直接持有时，具体使用人显示本人，不提供另一套使用人编辑。团队尚未补录时明确显示“待补录”，不自动把负责人当作使用人。人员后来停用时保留当前事实，可以明确更换或清空，不自动改成已退回。

本操作不生成转交单，不改变团队持有方、设备负责人、起始日期、长期/临时方式、预计归还日期、原分配标识或原交接快照。前后使用人姓名和操作者存入不可改写事件；设备版本递增，旧草稿须重新核对。它属于后续分配事实，原单不得绕过此依赖直接作废。

同团队更换负责人保留当前具体使用人；更换实际持有方时结束旧分配，新分配不继承旧使用人。遗失、报废及退回结束旧分配，找回不自动恢复旧使用人。若可安全作废后续转交或退回，恢复原分配时保留该分配原有使用人，不凭当前名册重建历史。
