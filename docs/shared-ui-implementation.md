## 新增接收对象表单

[PartyQuickCreate.vue](../web/src/components/PartyQuickCreate.vue)统一用于存量建账和交接表单，集中维护个人或团队名称、人员类型、所属单位、团队默认负责人及备注。两处页面统一显示“新增个人或团队”“对象名称”和“新增接收对象”，操作区复用既有按钮组。

组件接收调用方的 `allowed` 权限，并同时核对当前台账写权限。建账页使用台账写权限，交接页使用流转写权限；建账不再要求流转开关开启。真正的数据授权继续由原后端接口执行，前端参数不产生额外权限。

提交中禁用字段，并通过 `v-model:busy` 通知调用页面暂缓保存设备或草稿。相同表单内容重用请求标识；响应丢失后保留输入，成功后只发出新增对象事件。调用页面负责更新自己的名单及选中持有方或接收方，组件不直接办理设备或草稿。

身份、权限变化或组件退出时废弃未完成操作的界面回调，迟到响应不能重新填入名单或显示成功消息。刷新或离开后仍应先核对已创建对象，不承诺跨刷新保留请求标识。名单读取错误与新增表单错误分别显示和重试。

## 公共授权查询

[useAuthorizedQuery.ts](../web/src/useAuthorizedQuery.ts)集中处理授权页面的读取状态，包括加载、中文错误、刷新重试、当前成员和角色变化、请求先后顺序以及页面退出后的响应丢弃。每个调用页面独立保存结果，不引入跨账号的公共数据缓存。

| 读取入口 | 页面保留的业务差异 |
| --- | --- |
| 设备台账 | 搜索、分类、状态与持有方筛选 |
| 临时使用与到期列表 | 到期状态筛选与服务端业务日期 |
| 设备详情 | 路由设备标识、操作后的刷新和成功提示 |
| 单据列表与流转列表 | 单据筛选、列表用途及角色变化 |
| 建账人员团队名单 | 台账写权限、创建后的名单及持有方选择 |

新查询开始时清除旧结果；失败显示重试，不能当作空列表。失权时同步清空结果，恢复权限后重新读取；同一页面的新请求、身份、角色或路由变化会使旧响应失效。离开设备详情时不以缺失路由标识发起无效设备查询。

筛选仍在提交查询后生效，分页继续复用既有组件。复杂草稿编辑、附件归档及账号审核保留各自的业务步骤；本轮没有增加通用 CRUD 框架、依赖或新接口。

计入新增公共模块后，本轮前端业务源码净减少一百二十一行；检查代码和文档单独统计，不用其增量抵消复用带来的源码减少。

## 启动与连续操作体验优化

本轮为本地实现，未提交、推送、发布或修改生产配置。沿用现有 Vue、Vue Router、Supabase 和 CDN，不引入新的云产品、状态库或后台服务。

- 应用先挂载导航及当前页面，账号初始化并行执行。登录与注册按钮在服务配置就绪前保持禁用，业务页面仍等待有效身份和权限；初始化期间不误报功能尚未开放。验证回调参数仍在路由渲染前清除。
- 部署脚本以同一份白名单生成公开运行配置 JSON，并将其作为非执行的 JSON 数据嵌入 HTML。嵌入内容转义 HTML 分隔符，只包括公开 API 地址、公钥、schema、版本与功能开关，不序列化整个环境变量。正常发布后的启动无需额外请求配置文件；开发和旧部署保留文件读取兼容。配置读取在当前标签页内复用成功结果和在途请求，失败可重试。发布检测核对 HTML 配置与配置文件的版本、schema 一致。
- 导入、扫码、设备和单据编辑详情、账号管理、设置、密码等较重页面按路由加载；常用列表和登录仍随入口加载。二维码及识别等能力保留，识别模块仍在使用时加载。
- 常用列表通过 Vue 自带 `KeepAlive` 在内存中保留，最多六个页面实例。台账、到期、人员团队、流转与单据页返回时保留筛选及分页，立即展示已加载内容并后台刷新。相同有序记录集的新响应不重置当前页；结果范围或每页数量变化仍重置并限制有效页数。后台更新使用固定高度的提示区域，避免加载提示反复推开表格。浏览器后退使用路由自带滚动位置恢复。
- 同一账号的权限复查保留此前验证的界面，复查通过后更新可见页面数据；重复的在途复查合并，SDK 初始事件不重复读取，显式登录核对与认证事件不再重复查询。身份变化、退出、权限失效或复查失败清除旧资料，并销毁原身份的页面缓存；资料读取与申请 RPC 设置十五秒超时。后端身份及权限检查保持，不以页面缓存作为授权依据。
- 查询和提交公共工具统一处理保留页面的激活、停用和卸载。隐藏列表不因同一账号复查而查询；重新显示时刷新。停用时丢弃旧查询响应并重置提交、取消下载，迟到响应不能恢复页面、继续后续读取或触发文件保存。缓存只存在当前标签页内存中，不新增业务数据的本地持久化。
