## 当前工作

公共接收对象表单及授权查询已本地整理：建账与交接共用创建表单，五个读取入口共用加载、错误和旧响应丢弃逻辑；生产发布待单独授权。详见[本轮整理](shared-ui-implementation.md)。

故障登记及维修恢复已接入设备详情和历史；迁移 011 已获授权应用，保护交接日期不早于最近故障或维修。保持持有方、期限、原编号和正式快照；页面随本轮既有 CI/CD 发布，真实业务待本人验收，详见[本轮实施](asset-condition-implementation.md)。

设备转交及同团队负责人交接已获授权上线，沿用既有表单和事务。普通转交建立新分配；负责人交接保留原期限、分配身份和故障状况。迁移 010 已应用，页面随本轮发布，详见[本轮实施](transfers-implementation.md)。

逐设备临时延期、历史期限记录及独立到期查询已获授权上线，迁移 009 已应用，页面随本轮发布。没有自动延期演示设备，也未开启归还提醒邮件，见[本轮实施范围](temporary-use-implementation.md)。

账号页操作按钮已改用公共按钮组，与其他操作区统一间距并在窄屏换行。台账和到期列表共用同一个分页组件及条数配置，分页边界、范围文字和页码重置由公共组件维护；复用规则见[公共界面规则](screens-and-forms.md#公共界面规则)。

设备台账已补充分页及每页条数选择：默认二十条，支持十、二十、五十或一百条，重新查询或调整页大小回到第一页。采用现有完整筛选结果在页面内分页，设备和数据库接口不变，详见[台账实施](inventory-implementation.md)。

已按授权通过迁移 007 统一为创建年份后缀，应用侧使用单一 `GEAR_DB_SCHEMA`。原始迁移 001–006 保留；设备、单据和权限的云端核对通过，见[统一命名记录](schema-naming.md)。附件迁移顺延为 008，后续已按单独授权上云。

存量建账与台账已上线；已获授权上线[领入、分发、退回与打印](flows-implementation.md)，包括草稿、批量确认、部分退回及冻结快照。上线检查未办理交接；随后按用户单独授权，将三台库存演示设备临时分发给演示团队、部分退回一台，并新领入一台演示碎纸机。当前设备共五十一台，生成三张正式单据；另外两台仍由团队临时使用，原分发单快照保持不变。签字件的[部署](evidence-implementation.md)已按单独授权完成，包括私有桶、迁移 008 和独立函数；本轮开启页面入口，真实签字件的上传及人工核对归档待本人验收。只有各实施文档明确列出的接口和页面属于已实现内容。
