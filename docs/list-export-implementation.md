# 台账与临时使用清单导出

状态：已完成本地实现，全部七十一项检查（六十九项浏览器场景与两项 CSV 编码场景）、格式、静态检查、类型检查及构建通过；已获单独授权推送并通过既有 CI/CD 发布。本轮仅增加清单文件下载，不执行数据库迁移、配置更改或业务写入。统一进度见[实现状态](implementation-status.md)。

## 使用范围

设备台账和临时使用与到期列表提供“导出 CSV”，按点击时表单中的筛选条件重新读取全部符合条件的记录，不限当前分页，也不需要先点查询。导出不会改变页面已有结果、筛选或页码。管理员、经办人和查询人均可导出自己有权读取的清单；待审核或停用账号没有入口。

台账文件包含设备编号、原资产编号、序列号、名称、分类、品牌、型号、状态、状况、持有方、负责人、使用方式、起始日、期限、跟进人、位置、最近交接日期及备注。临时清单复用相同字段，再增加到期情况、服务端业务日期和提前提示天数。未知日期为空，不补造日期；纯日期不转换为 UTC 时间点。临时清单文件名使用服务端业务日，普通台账文件名使用东八区当前日期。

## 公共实现与文件规则

两处入口共用 [ListExport.vue](../web/src/components/ListExport.vue) 的忙碌、错误、权限变化和下载流程；字段映射集中在 [inventory-export.ts](../web/src/inventory-export.ts)，CSV 编码与文件下载集中在 [csv.ts](../web/src/csv.ts)。各页面复用原查询函数，不新增后端接口、云产品或依赖，也不为每种清单复制下载逻辑。

文件采用 UTF-8 BOM、中文标题和 CRLF 行结束；逗号、引号及多行备注按 CSV 转义。编号在文件内按原字符串保留，包括前导零和历史编号中的符号；空值写为空字段。潜在表格公式（含空白或控制字符前缀）增加文本前缀，避免普通设备字段变成可执行公式。

CSV 本身没有列类型。Excel 等软件直接打开时可能把纯数字旧编号或长序列号自动转成数字；需要精确保留时，应使用“从文本/CSV”导入并把编号、序列号列设置为文本。文件中的文本前缀用于公式防护，不使用可执行公式强制显示编号。空结果仍生成列标题并提示零条记录。

## 权限与失败处理

每次导出重新调用现有 `list_assets` 或 `list_due_assets`，由后端检查当前成员资格，不直接导出页面缓存。身份、角色或可用权限变化及页面退出会使正在等待的结果失效；旧结果不会触发下载。导出进行中禁用重复点击，失败显示中文错误并允许重试，不把失败伪装成空清单，不显示后端原始诊断。

文件只在浏览器中生成和交给浏览器下载，临时对象地址随后释放；不上传对象存储，不生成公开下载链接，不把真实导出资料写入仓库。公共源码和检查只含虚构数据；本地导出文件继续放在忽略的 `exports/` 或项目外。

## 验证与后续边界

新增两个 CSV 编码场景及六个浏览器场景，覆盖三种角色、跨页完整导出、未查询的新筛选、中文与前导零、公式防护、多行转义、服务端到期日、空结果、失败后重试入口、失权及离开页面后的迟到响应。浏览器使用虚构 Auth 与 RPC，检查真实下载内容，不连接生产服务。

本轮是日常清单导出。单据与附件关联清单、原件批量导出及网站、数据库、附件的整体备份恢复仍未实现；不能用 CSV 下载代替这些功能或恢复验收。真实 Excel 导入、实际登录后的下载和大陆访问仍待本人验收。本轮已获单独授权推送发布，使用既有 CI/CD；执行前保存只读基线，发布后核对业务数据与共享后端配置。线上版本、入口和 CSV 内容使用虚构 Auth/RPC 检查，不导出真实人员设备资料，不办理业务。本轮没有迁移或云配置操作。
