# 页面与打印文字线框稿

状态：供审阅的设计稿，不是可运行页面。以下人员、团队、编号和设备均为虚构示例。详细规则沿用[日常操作设计](daily-operations.md)。

## 1. 台账首页

进入系统后直接看设备列表，不另做占一屏的图表大屏。

```text
□ SB-0001   ZC-2019-08   笔记本    陈明        陈明    正常  2026-11-30
□ SB-0002   000126       智慧屏    综合组      李青    正常  长期
```

示例中另有 2 件在库故障，因此可用库存、使用中、已退上游三个数字不直接覆盖总量。实际实现为统计加说明，不能用故障数量重复凑总数。

### 操作规则

- 名称或编号点击后打开设备详情。型号、位置等次要信息放详情中，避免首页横向拥挤。
- 搜索同时覆盖内部编号、原资产编号、出厂序列号、名称、当前个人或团队、负责人。
- 切换筛选或翻页时清除当前勾选，防止误操作不可见的设备；首版不做复杂跨页选择。
- 分发要求所选设备全部在库且正常；转交或退回要求同一交出方。不可操作时说明原因，并允许移除不符合条件的设备。
- 查询人隐藏编辑和批量流转入口；后端仍需独立鉴权。管理设置仅管理员可见。
- 导出当前筛选结果，不默认导出全部数据；导出属于读取权限，查询人可导出台账的建议需随本稿评审。
- 首次建账未完成时显示“正在整理现有设备，统计仅含已登记设备”。未录入不等于库存为零。

## 3. 统一交接表单

按一个完整页面设计，避免小弹窗内塞入设备列表。通常从台账选好设备后进入。

```text

预计归还     [2026-11-30]

接收人       陈明（由接收对象带出）

                         [取消] [保存草稿] [确认交接]
```

### 三种操作的变化

| 操作 | 表单变化 |
| --- | --- |
| 团队分发 | 接收对象改为团队，接收负责人必填，具体使用人选填 |
| 转交 | 显示原持有方与移交人，选择新接收方及新期限 |
| 退回 | 接收方选经办人库存或上游；隐藏期限；清单逐件选正常/故障，故障补说明 |

一张分发或转交单共用一个期限。确需不同期限时分别开单，避免第一版增加每行日期编辑。退回时可汇集同一持有方名下来自不同历史单据的设备，系统按设备关联各自原流转记录。

新增个人只需姓名和人员类型；新增团队只需名称和负责人。可选资料不阻塞办理。日期或必填项错误就在字段旁提示，保留已填内容。

成功后跳转新单据详情，显示“已确认交接，签字件待回传”，提供打印和上传入口。确认过程中禁止重复点击；失败保留草稿内容，不能先显示成功再后台补交接。

## 4. 单据与附件

列表显示单号、类型、日期、交出方、接收方、设备数、单据有效性、凭证状态。签字件待回传和已归档分别筛选，作废单仍可查。

```text
分发单 FF-20261020-001          已确认 · 待核对
经办人库存 → 陈明              2026-10-20 / 2 件
[打印] [上传签字件]

签字件预览                    系统记录
[图片/PDF 第 1 页]             匹配单号：FF-20261020-001
                              接收人：陈明
                              设备数量：2
                              [ ] 已核对单据、签字及完整页数
                              [确认归档]
```

匹配结果仅供核对，不声称系统已识别手写签字真伪。上传后无结果显示“未匹配，请手动选择”；匹配到别的单据显示冲突，必须核对后关联，不能悄悄改变归属。没有签字件时显示上传引导。

## 5. A4 分发单样张

```text
                      示例单位
                     设备分发单

单据编号：FF-20261020-001            交接日期：2026年10月20日
交出方：经办人库存                  接收方：陈明
移交人：王宁                        接收负责人：陈明
使用期限：临时，预计2026年11月30日归还

序号  内部编号  原资产编号   设备名称    品牌型号   状况   备注
 1    SB-0001   ZC-2019-08  笔记本      示例型号   正常   含适配器
 2    SB-0003   —           电插板      —         正常   —

合计：2件
补充说明：________________________________________________

移交人签字：________________    接收人签字：________________
签字日期：__________________    签字日期：__________________

单号：FF-20261020-001            第1页/共1页         [二维码]
```

实际排版采用黑白 A4 纵向，清晰边框、可换行文字、足够手写空间。逐件一行，合计按行内件数计算；编号太长不得截断，优先换行或适当调整列宽。

- 领入单、转交单沿用同一结构，调整标题与交接方。
- 退回单将期限替换为退回原因，逐件显示正常或故障及说明。
- 多页重复表头、单号和页码；最后一页保留汇总和完整签字区，不拆开签字栏。
- 原件上传页数与打印页数供人工对照；不要求模型自动证明附件完整。
- 旧单重打使用当时快照，原单位抬头也保留。作废单显著标记“已作废”；草稿不使用正式单号。

## 6. 手机范围

只优先优化三个动作：搜索并看设备、查看单据、拍照或选择文件上传。拍照后可预览、删除重拍、增加下一页，再统一提交。手机端仍需登录与权限校验，不做独立 App。

## 下一轮审阅重点

优先确认首页信息是否够用、交接表单是否足够短、纸质签字区是否符合日常习惯。具体编号前缀、字号和颜色可在样稿验证时调整，无需现在逐项决定。

本稿未生成实际打印文件或浏览器原型，分页、长编号及手机上传交互均待实现阶段验证。技术选型继续搁置。
