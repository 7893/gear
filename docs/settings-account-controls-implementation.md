## 单位抬头

有效管理员在 `/#/settings` 读取和修改单位抬头。抬头为一至一百二十字的单行文字，必须填写修改原因；保留操作者、记录时间、前后抬头和请求标识。查询人与经办人不能读取此设置入口或调用接口。

修改只影响以后确认的单据。已确认、已作废或已签字的原单重打仍使用确认时快照；已存在的草稿在确认时使用当时抬头。不改设备、持有关系、单号、原件、邮件开关或到期提醒配置。

迁移 `202610190016_document_header.sql` 仅增加四个读写函数，不新增表、字段、触发器或业务数据，不替换已有函数。接口只返回抬头、版本及抬头修改历史，不暴露其他设置。写入复用设置单行锁、当前角色判断、版本校验和事件请求去重。超时重试返回最初结果；换内容、换操作者或过期版本拒绝，失权后不能重放旧请求。

## 登录后修改密码

已验证且已启用的登录用户从“我的账号”进入 `/#/account/password`。填写当前密码、新密码和确认密码，并明确确认此身份与同一认证项目的其他应用共享密码。新密码为十二至一百二十八个字符，两次一致；认证服务的原有策略继续适用。

当前密码验证使用官方 SDK 的独立内存客户端，不替换正常登录客户端，不把临时令牌或当前密码持久保存。提交前读取认证身份与本应用当前成员状态，临时重新登录后核对身份、成员及邮箱一致，再次读取当前状态后仅提交密码更新，不修改邮箱、metadata、角色或账号审核状态。

成功后退出临时会话和设备簿本地会话，仅清理设备簿自己的登录存储，提示正常重新登录；其他应用的存储保持。其他刷新会话和访问令牌的实际失效仍由现有认证服务决定，不能承诺其他应用所有访问令牌立即失效。连接中断可能已提交密码，不自动重试修改，页面提示先尝试新密码登录。

导航离开、身份变化或权限消失时清空敏感输入并取消后续步骤；已在服务端提交的密码变更不能由关闭页面撤回。迟到的临时登录响应仍清理临时会话，不允许继续改密或覆盖其他账号的正常会话。

## 管理员发起找回

账号管理中，为已验证、已启用且认证身份存在的账号提供“发送找回验证码”。点击时确认发送，重新核对管理员身份、目标成员的版本和邮箱；收件人固定为当前成员本人的邮箱，不接受另填收件地址，不由管理员指定新密码。

请求复用原有公开密码找回接口、现有 Gmail 认证邮件函数、资格核对、六位数字验证码、有效期与限流，不增加发信产品、模板、私有管理密钥、服务端重置接口或另一套待发队列。界面显示“已提交请求”，不将返回成功等同于已送达；超时提示先查收，不自动补发。现有认证邮件服务仍会独立核对收件账号资格。

这是一项调用现有找回能力的管理便利入口，不增加认证层的管理员特权或设备簿业务审计事件；原有公开找回入口保持。管理员不能读取密码或代收验证码，邮箱不可用仍需受控身份核对。

用户在找回页面输入本人邮箱，选择“已有找回验证码”即可验证已收到的码，不必先重发使原码失效。验证码不进入链接、URL 参数或持久存储；验证后继续原有资格检查与设置新密码步骤，不能绕过账号审核或停用。

## 公共能力与边界

主动改密和找回复用 `PasswordFields`、密码校验、内存认证客户端及本应用存储清理工具；账号管理和单位设置复用当前管理员判断，设置页复用授权查询、按钮组、错误提示和请求去重。RPC 的统一超时与错误处理由同一内部函数承担，调用参数仍使用运行配置的 schema。

不新增依赖、云产品、凭据或环境变量。未访问生产认证接口办理任何操作，未发送真实邮件或修改真实密码、DNS、CDN、证书及共享服务配置。前后端部署和迁移须在以后取得相应授权后进行；本轮没有创建新的 Git 提交。
